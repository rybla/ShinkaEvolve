<DESCRIPTION>
This update optimizes the generator to achieve higher `tm_sizes_average` and `used_vars_proportions_average` while maintaining a perfect `good_ratio`. 

Key improvements:
1.  **Context-Aware Application**: Instead of generating a random argument type for applications, it now pulls a type from the existing context with 60% probability. This significantly increases the likelihood that the argument term can be a `Var`, boosting variable reuse.
2.  **Strict Lambda Forcing**: When the target type is a function, the probability of generating a `Lam` is increased to 80%. This ensures deeper structural alignment with the type.
3.  **Asymmetric 75/25 Split**: The budget distribution for applications is shifted to 75% for the function and 25% for the argument, creating longer left-heavy spines.
4.  **Literal Diversity**: Literals now incorporate the current budget or context length to ensure `unique_subterms_proportions_average` remains high even in very large terms.
5.  **Hard Floor Termination**: Improved logic for low-budget scenarios to ensure a valid term is always returned, especially for function types.
