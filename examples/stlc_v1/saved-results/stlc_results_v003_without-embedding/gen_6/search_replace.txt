<DESCRIPTION>
The previous implementation had a critical bug: `Dict` was not imported, causing `good_ratio` to drop and term sizes to collapse. I will fix the import issue by using standard `list` for context, and more importantly, I'll refine the generator to push term sizes closer to the 100-node limit while ensuring variable usage is maximized.

Specifically:
1. Replaced `Dict` with a list of tuples for the context (avoiding import errors).
2. Increased the base case probability of picking a variable from context to improve `used_vars_proportions`.
3. Adjusted the budget splitting in `App` to ensure it consumes more of the 100-node limit.
4. Added a "force variable" path when variables are available but the budget is low.
</DESCRIPTION>
