<DESCRIPTION>
This edit implements a "Dynamic Tapered Budget Splitting" strategy. Instead of a fixed 92/8 split, the split starts more aggressively (96/4) to build a massive initial spine and then tapers down to 80/20 as the budget depletes. This ensures that argument branches have enough "residual fuel" to generate variables or small sub-terms rather than just literals, improving variable reuse. Additionally, it introduces a frequency-weighted context selection to further bias towards types that are already heavily populated in the environment.

        matches = [name for name, ty in ctx if ty == target_ty]

        # 1. Hard Floor Logic
        if budget <= 3:
            if matches and rng.random() < 0.99:
                return ("Var", matches[-1])
            
            if target_ty[0] == "Bool":
                return ("Bool", rng.random() > 0.5)
            if target_ty[0] == "Int":
                return ("Int", rng.randint(0, 10**6) + budget)
            if target_ty[0] == "String":
                return ("String", f"s_{len(ctx)}_{budget}_{rng.getrandbits(16)}")
            
            if target_ty[0] == "Fun":
                v_name = f"x{len(ctx)}"
                return ("Lam", v_name, target_ty[1], gen_term(target_ty[2], ctx + [(v_name, target_ty[1])], 1))

        # 2. Forced Abstraction
