<DESCRIPTION>
To improve `used_vars_proportions_average` and `applied_lambdas_proportions_average`, I will:
1.  **Prioritize Variable Application**: When generating an `App`, specifically look for variables in the context that can be applied to reach the `target_ty`.
2.  **Explicit Redex Generation**: Introduce a chance to generate an "Immediate Application" (a Lambda applied to an argument) even when not strictly required by the type. This directly boosts the `applied_lambdas` metric.
3.  **Context-Aware Argument Selection**: When generating a function for an `App`, try to pick an `arg_ty` that matches types already present in the context, increasing the likelihood of using existing variables as arguments.
</DESCRIPTION>
