def generate_type(rng: random.Random, depth) -> Ty:
    if depth <= 0 or rng.random() < 0.3:
        # Base types
        i = rng.randrange(0, 3)
        if i == 0:
            return ("Bool",)
        elif i == 1:
            return ("Int",)
        else:
            return ("String",)
    else:

        ret_ty = generate_type(rng, depth - 1)
        return ("Fun", arg_ty, ret_ty)

The generator builds types recursively, choosing between base types and function types based on depth and randomness.
