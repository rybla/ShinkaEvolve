```python
def generate_type(rng: random.Random, size_budget: int) -> Ty:
    """Generate a type with a given size budget."""
    if size_budget <= 1:
        # Base types
        i = rng.randrange(0, 3)
        if i == 0:
            return ("Bool",)
        elif i == 1:
            return ("Int",)
        else:
            return ("String",)
    
    # Function type: uses 3 nodes (Fun, domain, codomain)
    # So we split the remaining budget between domain and codomain
    remaining = size_budget - 1
    domain_size = rng.randrange(1, remaining)
    codomain_size = remaining - domain_size
    
    domain = generate_type(rng, domain_size)
    codomain = generate_type(rng, codomain_size)
    return ("Fun", domain, codomain)
```

For types, I'll use a size budget to recursively build function types, splitting the budget between domain and codomain to reach the target size. For terms, I need to track bound variables and generate applications, lambdas, variables, and literals while staying within the size budget.
