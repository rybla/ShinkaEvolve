<DESCRIPTION>
This update implements dynamic budget reallocation and smarter context exploitation to maximize term size and variable usage.
1.  **Context-Aware Application**: Instead of generating random function types for `App`, it first tries to find existing variables in the context that can be applied to reach the target type.
2.  **Budget Reallocation**: If a branch (like a variable lookup) fails or consumes very little budget, the remaining budget is passed back or used to deepen the alternative branches.
3.  **Variable Usage**: Increases the probability of selecting variables from the context and ensures that if a function type is required, it prioritizes `Lam` to introduce more variables.
4.  **Literal Diversity**: Adds more variety to literals to increase the unique sub-terms count.
</DESCRIPTION>
