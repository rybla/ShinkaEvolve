The main issue I see is that `used_vars_proportions_average: 0.00` - the variables are not being used. Looking at the code:

```python
if context and rng.random() < 0.3:  # 30% chance to use a variable
    var_name = rng.choice(context)
    return (
        ("Fun", ("Int",), ("Int",)),
        ("Lam", "x", ("Int",), ("Var", var_name)),
    )
else:
    ty, tm = generate_sample(rng, depth - 1, context)
    return (
        ("Fun", ("Int",), ty),
        ("Lam", "x", ("Int",), tm),
    )
```

The problem is:
1. The context is NEVER updated when creating a Lam - `context` is passed as-is to the recursive call, so "x" is never added to the context
2. Even when `context` has values, the code checks `if context and rng.random() < 0.3` - but the context is always empty because the variable is never added!

The fix is to add the parameter "x" to the context when recursing:
```python
else:
    new_context = context + ["x"]
    ty, tm = generate_sample(rng, depth - 1, new_context)
    return (
        ("Fun", ("Int",), ty),
        ("Lam", "x", ("Int",), tm),
    )
```

I also notice that the depth parameter is not being used to terminate recursion in the else branch - it should pass `depth - 1` to ensure termination. Additionally, there's a depth check missing in the condition - it should verify `depth > 0` before attempting to use a variable, otherwise we could generate invalid terms at depth 0.
