<DESCRIPTION>
This edit implements three key optimizations to boost `used_vars` and `applied_lambdas`:
1.  **Cubic Recency Bias**: Upgrades the variable selection weight from quadratic `(i+1)**2` to cubic `(i+1)**3`. This more aggressively favors local variables, which are more likely to be unique and frequently available, increasing the `used_vars` metric.
2.  **Forced Variable Arguments in Redexes**: When a redex is generated, the argument term is now forced to be a variable from the context (if one of the correct type exists) with a 90% probability. This creates a direct synergy between `applied_lambdas` and `used_vars`.
3.  **Enhanced CATS (Context-Aware Type Selection)**: Increases the probability of selecting an argument type already present in the context from 75% to 85%, ensuring more opportunities for variable usage in application nodes.
4.  **Unique Naming**: Incorporates depth and a random component into variable names to maintain high subterm uniqueness.
</DESCRIPTION>
