<DESCRIPTION>
To maximize `used_vars_proportions_average` and `applied_lambdas_proportions_average`, I am implementing a "Forced Variable Argument" strategy. When a redex is injected, the generator now actively searches the context for a variable matching the argument type. If found, it uses that variable with high probability instead of recursing into `gen_term`. This ensures that every redex injection also counts as a variable usage. Additionally, I've refined the `gen_term` budget split and type selection to favor types already present in the context more aggressively.
