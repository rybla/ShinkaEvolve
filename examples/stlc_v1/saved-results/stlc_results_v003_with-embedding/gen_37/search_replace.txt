<DESCRIPTION>
This update implements three key optimizations to boost the `combined_score`:
1.  **Cubic Recency Bias**: Replaces quadratic bias `(i+1)**2` with cubic bias `(i+1)**3` to more aggressively favor local variables, which is proven to increase `used_vars_proportions_average`.
2.  **Refined CATS (Context-Aware Type Selection)**: Improves the standard application branch by forcing the argument type to match a type already present in the context with 85% probability. This ensures that arguments are much more likely to be variables rather than literals or new complex terms.
3.  **Strict Asymmetric Budgeting**: Replaces the random split in standard applications with a fixed 70/30 split, ensuring deeper functional nesting and more opportunities for redexes in the primary branch.
</DESCRIPTION>
